API INTEGRATION
===============
  ✅ GET /api/kpis
     Fetches KPI metrics from shared database
     Returns: totalIncentivesProcessed, errorRate, avgProcessingTimeMs,
              pendingIncentives, slaCompliance, avgAccuracy

  ✅ GET /api/payouts
     Queries Incentive table with Employee joins
     Returns: Extended incentive records with employee details

  ✅ GET /api/errors
     Filters incentives where hasError = true
     Supports: errorType, region filters
     Returns: Error records with classification

  ✅ POST /api/validate-payouts
     Validates incentives against expected vs actual
     Returns: Mismatches and delays detected
